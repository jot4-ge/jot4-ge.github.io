# jot4-ge · Portfólio

Portfólio pessoal de João Guilherme — desenvolvedor fullstack e estudante de Engenharia de Software na UnB.

🔗 **[jot4-ge.github.io](https://jot4-ge.github.io)**

## Stack

- **React** + **TypeScript** + **Vite**
- **anime.js**, **GSAP** e **Lenis** para animações e smooth scroll
- Bilíngue (PT/EN) e tema claro/escuro
- Deploy automático via GitHub Actions

## Rodar localmente

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
